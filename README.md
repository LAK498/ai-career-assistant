# AI Career Assistant

An NLP-based career recommendation and skill-gap analysis web application built with Python and Streamlit.

## Features

- Technical skill extraction from a user's profile
- Career-role recommendation
- TF-IDF + cosine similarity based matching
- Career match score visualization
- Skill-gap analysis
- Personalized learning roadmap
- Student/fresher-friendly interface
- No API key required
- Deployable directly from GitHub using Streamlit Community Cloud

## Career Roles Included

- Python Developer
- Data Analyst
- Data Scientist
- Machine Learning Engineer
- Web Developer
- Cybersecurity Analyst

## Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- Plotly
- NLP / TF-IDF
- Cosine Similarity

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## GitHub Repository Description

> AI Career Assistant using NLP to recommend career paths, identify skill gaps and generate personalized learning roadmaps.

## Important Note

This is an educational AI/NLP project. It uses a predefined career-role knowledge base and TF-IDF/cosine-similarity matching. It does not claim to predict a person's career with certainty.
